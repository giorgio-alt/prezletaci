# Fotografická knihovna pro GitHub

Tato složka obsahuje optimalizované kopie fotografií kampaně se zachovanými názvy
a strukturou adresářů. Každý JPEG má nejvýše 950 000 bajtů, maximální rozměr
2 400 px a odstraněná metadata.

Lokální složka `Originální Fotky` zůstává beze změny a není součástí repozitáře.
Knihovnu lze znovu vytvořit skriptem `scripts/compress_photos_for_github.py`.
