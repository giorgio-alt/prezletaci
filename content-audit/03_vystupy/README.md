# Evidence textových podkladů

## Struktura

- `00_zdrojove_zipy` — neměnné kopie čtyř dodaných ZIP archivů.
- `01_rozbaleno` — pracovní rozbalená kopie 42 zdrojových souborů.
- `02_extrakce` — strojově získaný text, technický inventář CSV/JSON.
- `03_vystupy` — redakční výstupy, kategorizace a data připravená pro další import.

## Hlavní závěry

- Dodáno bylo 11 kandidátských medailonků, tedy podklad ke každému kandidátovi evidovanému v Campaign HQ.
- Kontaktní XLSX obsahuje osobní údaje a je určen pouze pro interní potřebu; nesmí být publikován ani přenesen do veřejného webového obsahu.
- Nejsilnější okamžitě využitelné tematické podklady jsou zeleň a architektonická studie radnice.
- Texty k developerům, politickým tvrzením a hasičům vyžadují faktickou, zdrojovou a u vybraných tvrzení právní kontrolu.
- Dva soubory jsou binárně duplicitní: `Zastupitelstvo vymezení poz b vrátka 27.07.2011.pdf` a `dk4a_zapis-7-11.pdf`.
- Dva další soubory mají shodný extrahovaný text: `dx2b_zapis-6-2014-2.pdf` a `dx2b_zapis-6-2014-3.pdf`.

## Publikační stav

Medailonky jsou redakční návrhy. Před zveřejněním musí každý kandidát potvrdit svůj claim, pracovní roli, délku praxe a případná konkrétní tvrzení. Tematické články jsou zatím osnovy, nikoli texty schválené k publikaci.
